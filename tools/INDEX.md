# Tools created by the agent. Register every tool here.

| Tool | Purpose | Created |
|------|---------|---------|
| scheduler.sh | Serialized entrypoint for wake/reflect runs: global flock (prevents overlapping sessions), precondition check, runs preflight, items collect + precheck (wakes), picks the series slot and writing model, launches opencode, then refreshes the public mirror (tools/mirror.py, Pi-only deploy key) when the session committed. Logs to logs/scheduler.log | 2026-08-30 |
| install_scheduler.sh | Installs/enables the systemd user units (wake hourly at :00, reflect daily 06:30, dedicated agent Chrome + nightly 03:10 restart). Idempotent; rerun after editing units | 2026-08-30 |
| preflight.sh | Deterministic setup before every session: repo pull + push of pending work, CDP health with one self-heal restart, stale-daemon kill, `x session` verified as @GCBullGlasses. Fails loudly rather than launch a doomed agent | 2026-09-01 |
| xcli/x | The `x` CLI (ADR 0001): all X reads/writes via one JSON envelope (session/status[many URLs]/sweep/thread/notifications/profile/analytics[Premium per-post: impressions, engagements, detail expands, profile visits], reply/post/quote[--media]/like/repost/follow/delete/bio/pin). Owns its own Chrome tab per invocation; counts the daily caps itself (xcli/caps.py) and registers every published item in items.json | 2026-09-03 |
| stats.py | Only interface to memory/stats.json: `summary` prints the ~20 lines a wake needs; `record` upserts today's snapshot from `x status` envelopes, inheriting each item's kind from items.json (write verbs are authoritative — takes no longer land as kind=reply). Replaced reading a 120 KB file on every turn | 2026-09-06 |
| state.py | Working state in memory/state.json (caps, author hits, readouts, do-not-reply, used angles, deadlines, sweep targets): `show` + field verbs. Replaced hand-editing MEMORY.md 49× in 12 wakes | 2026-09-06 |
| precheck.py | Deterministic gate before each wake: notifications, `x sweep` (round-robin, `--sweep-max 20` per wake), deadlines and due series slots (tools/series.py) since the last LLM wake. exit 10 = nothing new, agent not launched; any failure launches. Fresh posts by authors who blocked us and `like` notifications are not signals on their own. Saves envelopes to logs/precheck-latest.json for the wake to reuse | 2026-09-06 |
| items.py | One row per published item in memory/items.json, measured at t+1h/6h/24h/72h by `collect --due` from scheduler.sh (x profile + status + analytics, no LLM). The wake only runs `add` after each write verb, `mark` when an author replies, `summary` to read; reflection runs `report --by series|model|kind`. Replaced guessing per-post trajectories from daily stats.json snapshots | 2026-09-06 |
| render.py | The only path from data to an image: `metrics` (daily followers card from stats.json + items.json) and `card --title --body` (postmortem/note), rasterized by the agent Chrome from a template, after a scan that refuses secrets, paths, emails, the employer and any blocking account. Writes renders/<name>.png + .json sidecar (sha256 + data) that `x … --media` requires | 2026-09-06 |
| series.py | The three fixed daily slots (metrics 07:30, take 13:00, postmortem 21:30) in memory/series.json: `due` for precheck/scheduler, `model <series>` picks and records the alternating writing model (two-week A/B, per series) that scheduler.sh passes to `opencode run --model`; a slot is done when items.json has today's item | 2026-09-06 |
| targets.py | The observation list by rule: `evaluate|add` read X (`x profile` + `x replies`) and accept only 5k-80k accounts that answer strangers with a clean bio; `review` drops targets after 10 unanswered replies; `mega add|drop` keeps the separate mega lane. Every change lands in memory/targets-log.md | 2026-09-06 |
| rate.py | The owner's 1-10 ratings of posts (memory/ratings.json): `add`, `show` (joined to items.json, by model), `pending`. Read by the reflection next to items.py report | 2026-09-06 |
